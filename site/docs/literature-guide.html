01

二、调研方法与检索记录

  • 先用中英文关键词在学术数据库中检索，再沿高被引综述的参考文献和被引文献扩展。英文可用 Web of Science、Scopus、IEEE Xplore、ScienceDirect、Google Scholar；中文可用中国知网、万方、维普。
  • 按“检索 → 题名摘要初筛 → 精读 → 归纳比较 → 联系本对象”的顺序推进。精读文献应记录对象、方法、实验或仿真条件和主要结论。
  • 在报告附录中给出检索记录：数据库、检索式（关键词组合）、检索日期、命中数量、入选数量。
02

各主题起步方向与关键词

以下只用作检索起点，不能代替系统检索。各主题“必须回答的问题”见作业说明主页。

A　平台构型与布局

起步方向。 Stewart 平台与立方构型；航天微振动隔离；引力波探测中的多级多轴隔振平台（如 Advanced LIGO 的 HAM-ISI、BSC-ISI）；光刻机等精密设备的软/硬支撑隔振；原子干涉重力仪的低频主动隔振；准零刚度与负刚度等主被动复合方案。

关键词。 Stewart 平台 / Stewart platform、hexapod；六自由度主动隔振 / six-axis active vibration isolation；多级隔振 / multi-stage isolation；软支撑、硬支撑 / soft mount、active hard mount；准零刚度 / quasi-zero stiffness；音圈电机 / voice coil actuator；作动器与传感器配置 / actuator–sensor placement；微振动隔离 / micro-vibration isolation。

B　动力学与控制性能

起步方向。 多自由度平台动力学建模与模态耦合；同位与非同位控制；反馈系统的基本性能限制；多变量反馈的奇异值分析；低频隔振中的倾斜-水平耦合；测量链动态与相位滞后。

关键词。 固有频率 / natural frequency；模态耦合 / modal coupling；传递率 / transmissibility；同位、非同位控制 / collocated、non-collocated control；零极点交替 / pole-zero interlacing；右半平面零点 / right-half-plane zeros；非最小相位 / non-minimum phase；传输零点 / transmission zeros；Bode 灵敏度积分 / Bode sensitivity integral；性能基本限制 / fundamental limitations；倾斜-水平耦合 / tilt-horizontal coupling。

C　低频测量与传感器融合

起步方向。 低频惯性传感器综述；倾斜-水平耦合与无倾斜（tilt-free）测量；转动传感器与倾斜减除；互补滤波与传感器融合；传感器校正；天钩阻尼；速度传感器的低频相位补偿。

关键词。 惯性传感器 / inertial sensor；检波器 / geophone；地震计 / seismometer；传感器自噪声 / self-noise、noise floor；转动传感器 / rotation sensor；互补滤波 / complementary filter；传感器融合 / sensor fusion；融合频率 / blending frequency；传感器校正 / sensor correction；天钩阻尼 / skyhook damping；相对位移传感器 / relative displacement sensor。

D　先进控制算法

起步方向。 速度反馈与天钩阻尼等基线方法；光刻机等精密设备中的解耦加 SISO 工程实践；H∞ 混合灵敏度与 μ 综合；约束处理的模型预测控制；FxLMS、RLS 自适应前馈；原子重力仪隔振中的滑模控制；神经网络与强化学习等学习型方法。

关键词。 H∞ 控制 / H-infinity control；混合灵敏度 / mixed sensitivity；μ 综合 / μ-synthesis；线性二次高斯 / LQG；模型预测控制 / model predictive control；自适应前馈 / adaptive feedforward；滤波-x 最小均方 / filtered-x LMS；递推最小二乘 / recursive least squares；滑模控制 / sliding mode control；强化学习 / reinforcement learning；解耦控制 / decoupling control。

七、评价要点与常见失分

以下为定性评价要点，不公布分值或权重，与公开正文“不包含评分规则”的约定一致。

评价要点

  • 覆盖完整：四个主题齐全，“必须回答的问题”逐条有回应。
  • 分析深度：有归纳和比较，能说明方法的适用条件与局限，而不是罗列文献摘要。
  • 联系对象：结论能落实到本作业平台，综合章的启示清楚，且可供后续成员使用。
  • 文献质量：数量、时效和英文期刊占比达标，代表性强，引用准确、规范。
  • 表达规范：结构清晰，图表规范并注明来源，术语和符号前后一致。

常见失分

  • 仍按“四选一”只写一个主题，或某个主题明显缺写、敷衍。
  • 堆砌文献摘要，没有比较表，也没有对适用条件与局限的分析。
  • 只介绍通用原理，不联系本作业平台；综合章空泛，或与各主题章节脱节。
  • 两名调研成员的章节术语、符号不一致，结论相互矛盾，或内容大量重复。
  • 参考文献格式混乱，正文没有对应引用，文献信息无法核实或与原文不符。
  • 图表未注明来源，或直接截图、复制他人图表而不注明出处。
  • 越界替代后续任务：在调研报告中给出具体整定参数或未经验证的“预期性能”。
